# Product status

Revelio is a backend-free personal Bitbucket Cloud review workspace.

## Shipped locally

- Direct Bitbucket connection, saved repository scope, progressive inbox, and
  session/passphrase/passkey credential modes.
- Honest query validation, diff review, comments, review outcomes, durable local
  checkpoints, and re-entry on supported signals.
- Workbench Graphite UI with light/dark themes, responsive review workspace, and
  core keyboard navigation.
- Synthetic unit and browser coverage; no live-provider claim.

## Backlog

- Verify live CORS, token scopes, activity/re-entry signals, inline anchors,
  mutations, and approval reset.
- Add complete reason/CI/age/size queries, autocomplete, saved rules, grouping,
  and explainable suggestions.
- Improve comparison/viewed state, caching, rate-limit and targeted retry UX,
  command palette, thread history, stacked PRs, multiple connections/providers,
  and encrypted drafts/content.
